# 右手压力图表手指颜色图例设计

## 目标

在 Web 控制台的右手传感器图表标题旁显示颜色图例，让操作者能直接识别每条曲线对应的手指 ID。

## 界面

- 在“法向压力”“切向压力”“接近觉”三个标题右侧分别显示相同图例。
- 图例内容为“手指 1”“手指 2”“手指 3”，并使用与曲线一致的色点。
- 颜色映射保持现状：手指 1 为 `#002fa7`，手指 2 为 `#e4002b`，手指 3 为 `#5f6368`。
- “手指位置”图不添加该图例，因为它同时包含左右手数据。

## 实现约束

- 使用标题旁的 HTML/CSS 图例，不把文字绘制到 Canvas。
- 复用现有颜色映射，不引入依赖或新的绘图库。
- 图例在窄屏下允许换行，不遮挡图表。

## 验证

- 模板测试确认三个右手传感器图表均显示三个手指标签。
- 确认图例颜色与 `chartSeries()` 的曲线颜色映射一致。
- 运行现有 Web 模板及相关测试。
